# Bloom's Taxonomy Verb Reference

Quick reference for matching learning outcome verbs to question patterns. The course-description-guide.md tells course authors to use upper-level Bloom's verbs in learning outcomes. This file shows which verb produces which kind of question.

## Lower Levels (Avoid in Course Outcomes)

These verbs do not produce testable outcomes. The course-description-guide flags them as weak.

| Verb | Why Weak |
|------|----------|
| understand | Cannot be observed or tested |
| know | Same problem |
| learn | Describes a process, not an outcome |
| be aware of | Bare minimum, not a skill |
| appreciate | Subjective and untestable |
| become familiar with | Not specific enough |

A learning outcome using one of these verbs cannot drive a good quiz question. Reject and ask for a stronger verb.

## Remember Level (Recall Questions)

| Verb | Question Pattern |
|------|------------------|
| identify | Recall: "Which of these is X?" |
| name | Recall: "What is the name of X?" |
| recall | Recall, plain |
| list | Recall: "List the steps in X" (open-ended, not multiple choice) |
| recognize | Recall with a visual or example |
| state | Recall: "State the value of X" |

Use according to course goals. K-12 introductory courses, language courses, and any subject where memorization is itself a learning objective legitimately use Remember-level outcomes. Adult professional and upper-level academic courses usually aim higher.

## Understand Level (Recall + Simple Scenario)

| Verb | Question Pattern |
|------|------------------|
| explain | Open-ended written response, or scenario where student picks the right explanation |
| summarize | Open-ended written |
| classify | Scenario: "What category does this example fit?" |
| compare | Comparative question |
| describe | Open-ended written |
| interpret | Scenario with data: "What does this reading tell you?" |

## Apply Level (Scenario + Applied Calculation)

| Verb | Question Pattern |
|------|------------------|
| apply | Scenario: realistic situation + correct application |
| demonstrate | Hands-on, often video script or in-person check, but can be scenario |
| use | Scenario or applied-calculation |
| implement | Scenario: "How would you implement X here?" |
| solve | Applied calculation |
| calculate | Applied calculation |
| operate | Scenario: "Given this state, what is the next operation?" |

## Analyze Level (Comparative + Multi-Step Scenario)

| Verb | Question Pattern |
|------|------------------|
| analyze | Multi-step scenario: "Given this complex situation, what is going on?" |
| differentiate | Comparative: "Which of these is the right tool for X situation?" |
| compare | Comparative |
| contrast | Comparative: "How does X differ from Y in this situation?" |
| contextualize | Scenario with sources: "Place this event in its context using the surrounding evidence." |
| interpret | Scenario with data or text: "What does this reading or passage tell you?" |
| attribute | Scenario: "Whose perspective does this passage reflect, and how do you know?" |
| diagnose | Scenario: "What is wrong here?" |
| troubleshoot | Multi-step scenario |
| examine | Scenario with data |

## Evaluate Level (Comparative + Hard Scenario)

| Verb | Question Pattern |
|------|------------------|
| evaluate | Comparative or scenario with judgment |
| critique | Comparative: "Which approach is better and why?" |
| argue | Scenario: "Take a position and defend it with at least two pieces of evidence." |
| weigh | Comparative: "Which of these factors carries more weight, and why?" |
| recommend | Scenario: "What do you recommend in this situation?" |
| defend | Scenario: "Why is this the right call over the alternatives?" |
| judge | Scenario with judgment |
| prioritize | Scenario: "Given limited time, what comes first?" |

## Create Level (Hard Scenario + Open-Ended)

| Verb | Question Pattern |
|------|------------------|
| design | Hard scenario: "Design a solution for X" (open-ended) |
| synthesize | Hard scenario: "Pull these sources together into one coherent argument" |
| compose | Open-ended written |
| construct | Open-ended or hard scenario |
| develop | Open-ended |
| produce | Open-ended |
| plan | Hard scenario: "Plan the steps to accomplish X" |

Note: Create-level outcomes are often hard to test in a multiple-choice format. Consider scenario-based decision-making questions where the student picks the best plan from candidates.

## Verb Selection Quick Guide

If the course outcome uses a verb at:

- **Remember level** → recall questions
- **Understand level** → mostly scenario, some recall
- **Apply level** → scenario or applied-calculation
- **Analyze level** → comparative or multi-step scenario
- **Evaluate level** → comparative with all-plausible options, hard scenario
- **Create level** → hard scenario, design questions

Match the question level to the outcome level. A learning outcome that says "Apply the Mohs scale" should produce apply-level questions, not remember-level questions. A learning outcome that says "Evaluate competing audio routing options" should produce evaluate-level questions, not apply-level.

When the outcome verb and the easy questions don't match, raise the question difficulty rather than weakening the outcome.

## Subject-Specific Verb Mixes

Different subjects naturally weight Bloom levels differently:

- **Technical / trade / vocational courses** lean on Apply and Analyze: apply, demonstrate, troubleshoot, diagnose, calibrate, calculate.
- **History, literature, and social sciences** lean on Analyze and Evaluate: compare, contrast, contextualize, interpret, attribute, argue, evaluate, weigh, defend.
- **Lab science and engineering** mix Apply and Evaluate: calculate, diagnose, evaluate, critique a method.
- **K-12 introductory and language courses** legitimately use Remember and Understand: identify, name, recall, classify, summarize, describe.
- **Design and creative courses** lean on Create and Evaluate: design, synthesize, compose, critique.

The toolkit picks the verb mix from the course's voice guide and learning outcomes. Do not import a trade-leaning verb list into a history course or vice versa.
